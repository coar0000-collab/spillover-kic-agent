# SPILLOVER — 미국 정책 충격의 한국 자산 전이 위험 진단 AI Agent

국부펀드 KIC AI 에이전트 공모전 출품작

미국의 관세·수출통제·통화정책·선거 발표를 감지해 원문을 판독하고, 한국 자산(KOSPI·원/달러·섹터)으로 어떤 경로로, 얼마나 번지는지를 **출처와 함께** 진단합니다.
설계 원칙은 하나입니다. **검증된 것만 예측하고, 예측할 수 없는 것은 범위와 근거로 제시한다.**

## 핵심 결과 (사전 검증)

| 항목 | 결과 | 비고 |
|---|---|---|
| 사례 라이브러리 | 2018.1~2026.10 미국 정책 이벤트 **164건** | 연방관보 문서 1,266건 선별, 동시 이벤트 66건 교란 표시 |
| 한국 다음 세션 방향 | 정책 이벤트 **75%** 적중 (평소 거래일 65%) | 미국 장 마감 반응 기반, 과거 사례로만 학습(시간순) |
| 향후 5일 방향 | 어떤 모델도 기준선 수준(48%) | 예측하지 않고 범위·근거로 제시 |
| 위험 크기 상위 1/3 경보 정밀도 | 52% → **70%** (국면·중국 수출 반영, 68건) | 무작위 33% |
| 경로 분해 | 통화정책: 미국 시장 49% / 중국 대상: 중국 경로 +14%p / 한국 직접·무역: 반도체 경로 +30~42%p | 한국 5일 반응 설명력(R² 증분) |

### 프로토타입 v0 사후 검증 (2026년 실제 이벤트 3건)

| 이벤트 | 조치 판정(원문) | 다음 세션 | 5일 범위 / 실제 | 섹터 고유 영향 |
|---|---|---|---|---|
| 2026.10.28 로봇·산업기계 232조 | 협상 지시(관세 미부과) ✅ | 하락, 실제 -3.5% ✅ | ±7.3% / -5.5% ✅ | 작음, 실제 +0.6%p ✅ |
| 2026.1.14 반도체 232조 | 관세 25% ✅ | 상승, 실제 +0.9% ✅ | ±6.7% / +4.0% ✅ | 큼, 실제 -5.4%p ✅ |
| 2026.7.23 301조(한국 12.5%) | 관세 12.5% ✅ | 상승, 실제 +1.0% ✅ | ±11.5% / -21.2% ❌ | 대상 섹터 없음 |

7/23 이후 급락은 반도체 재평가·레버리지 청산 등 정책 외 요인이었습니다. 본선에서 뉴스 교차확인(GDELT)으로 보강합니다.
10/28 포고문은 제목("Adjusting Imports")만 보면 관세로 분류되지만, 원문은 관세 없이 180일 협상만 지시합니다. Verifier가 이 오분류를 잡아냅니다.

## 구조

```
Sentinel ─▶ Policy Analyst ─▶ Transmission ─▶ Quant ─▶ Risk Scorer ─▶ Verifier ─┐
(감지)       (원문 구조화)      (경로·노출도)    (정량화)   (위험 크기)     (검증)    │
   ▲ 관련성 0.3 미만이면 종료                                     반려 시 재실행(최대 2회) ┘
```

| 노드 | 역할 | 사용 데이터·도구 |
|---|---|---|
| ① Sentinel | 대통령 문서 감지, 관련성 점수화 | Federal Register API |
| ② Policy Analyst | 원문에서 조치 유형·관세율·협상 기한·대상 품목 추출 | govinfo 원문 (v0 규칙 기반 → 본선 LLM 구조화) |
| ③ Transmission | 대상 섹터의 대미 수출 노출도, 이벤트 유형별 경로 가중치 | UN Comtrade API, 경로 분해 결과 |
| ④ Quant | 유사 사례 검색, 변동성 국면 보정, 미 반응일 서프라이즈 | 사례 라이브러리, 시장 데이터 |
| ⑤ Risk Scorer | 이벤트 강도, KOSPI 5일 예상 변동 범위, 섹터 직접 영향 | ④ 결과 |
| ⑥ Verifier | 주장별 출처 확인, 제목·원문 판정 대조, 동시 이벤트 교란 표시 | 사례 라이브러리 |

모든 수치는 도구(API·계산)가 산출하고, 각 주장에 출처를 붙입니다. 실행 시점(`as_of`) 이후의 데이터는 사용하지 않습니다.

## 빠른 실행

```bash
pip install -r requirements.txt

# 에이전트 실행: 지정한 날짜 기준 최근 2일의 미국 대통령 문서를 감지해 진단
python agent/spillover.py 2026-10-28

# 사후 검증: 에이전트 판단과 실제 시장 결과 비교
python agent/posthoc.py 2026-10-28
```

결과는 `runs/run_<날짜>.json`, `runs/posthoc_<날짜>.json`에 저장됩니다. 저장소에 3건의 실행 기록이 포함돼 있습니다.

## 전체 재현 (데이터 수집부터)

```bash
python pipeline/fetch_market.py   # FRED·Yahoo Finance 시장·거시 데이터
python pipeline/fetch_fr.py       # Federal Register 관세·수출통제 문서
python pipeline/fetch_trade.py    # UN Comtrade 한국 섹터별 수출(미국·중국 비중)

python pipeline/analyze2.py       # 시차 전이·위험 크기 예측
python pipeline/factors.py        # 확장 요인 27종 일별 데이터셋
python pipeline/fit_next.py       # 한국 다음 세션 예측(요인 그룹별 비교)
python pipeline/fit_event.py      # 위험 크기·경로 분해
```

## 검증 방법

- **시간순 검증**: 각 이벤트는 그 이전 사례로만 학습한 모델로 평가합니다.
- **정보 시점 정렬**: 미국 장 마감 후 발표는 미국 익일 반응과 한국 다음 세션 기준으로 측정합니다.
- **정규화**: 직전 120일 변동성 대비 z-score를 씁니다. 섹터는 KOSPI 대비, EWY는 S&P500 대비 시장모형 잔차로 계산합니다.
- **노출도**: 전년도 무역 데이터만 사용하고, 수출 지표는 발표 시차 2개월을 반영해 미래 정보를 배제합니다.
- **교란 표시**: ±3영업일 안에 다른 이벤트가 겹치거나 코로나 급락기, 국내 비상계엄 기간에 해당하면 표시합니다.

## 한계

- 원문 구조화(v0)는 규칙 기반입니다. 본선에서 LLM(JSON 스키마) 구조화와 규칙 교차검증으로 확장합니다.
- 노출도 효과는 방향은 맞지만 통계적으로 유의하지 않습니다(t=1.1). 기업 단위 노출도(DART 지역별 매출)로 보강할 예정입니다.
- 정책 외 요인에 의한 급락은 현재 구조로 분리하지 못합니다. 뉴스 교차확인을 추가합니다.
